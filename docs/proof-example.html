Abstract

This software example connects registered synthetic transport data to an editable scientific figure, an immutable journal-style proof and revision-specific discussion. It does not represent experimental evidence.

Data and source. The input is a registered synthetic bias sweep. Its source run, exact artifact hash and plot recipe are retained with this proof. The original values and acquisition order are unchanged.

Figure composition. Three Interact adds an editable panel label and annotations. Stable element identifiers let a reviewer point to a particular object. Editor history and assets are frozen with the generated figure.

Revision review. A saved proof is a new revision. Comments on Figure 1, its caption or an individual element remain attached to that version. Subsequent edits create another proof and do not overwrite the earlier discussion.

Reproducible composition. The curve is imported as an image panel. Typography, panel labels and additional scientific components are composed above this panel in the editor. Keeping the scene as an independent document makes those annotations reusable: the same element identifiers can be inspected by a person or an agent, and the scene can be reopened without rebuilding the original computational environment. The frozen plot recipe records how the source variables were mapped to the axes. A new style or variable selection should first be generated in the plotting workspace and then imported into a new composition. The illustration here uses artificial values solely to demonstrate the software workflow. Its apparent shape is not evidence for a physical model, an experimental mechanism or numerical convergence.

Version boundaries. Revision one keeps the originally obscured panel label and the corresponding review comment. Revision two restores the label above the image. The source input hash remains the same while the figure and scene hashes change. These identifiers allow the discussion to distinguish a presentation correction from a change to the underlying data. Exported PDF and HTML packages are self-contained reading copies; the scene and resource files remain the editable representation. Local review comments can point to the document, caption, full figure or a stable element identifier.
