# 0.5.1 独立 agent 使用评审与改进

2026-10-06。两个 agent 分别实际使用浏览器和命令行；测试目录均为标明的合成数据。原始反馈保留在 [界面评审](agent-review-ui.md) 和 [命令行评审](agent-review-cli.md)。

| 实际发现 | 改进 |
|---|---|
| 编辑入口需要滚动查找 | 工作区选择移到运行详情前，并在滚动时保持可见；校样区给出操作步骤和版本评论跳转 |
| 从已发布校样卡片进入后，版本列表缺少上下文 | 校验登记的校样来源清单，定位到源运行的草稿和全部直属校样，并选中打开的精确版本 |
| 生成进度和完成反馈不清楚 | 区分渲染和生成阶段；两个保存按钮保持禁用直到服务确认；显示新版本 ID，错误保留画布并可重试 |
| 连续修改文字和字号后立即保存时，属性重绘丢值且可能与自动保存冲突 | 按元素 ID 和属性提交待处理输入；自动保存单次在途，显式保存等待确认和最新哈希，确认超时给出可重试错误；保留并发版本检查 |
| 深色主题文字对比度偏低 | 宿主正文采用编辑器当前主题的前景与背景变量；浅色工具条独立配色 |
| 文章和画布保存含义不清楚 | 明确图形自动保存、文章需提交表单，并显示文章保存反馈 |
| doctor 显示旧的安装版本 | 同时记录实际加载版本、安装发行包版本和模块路径；刷新本地安装后均为 0.5.1 |
| 绘图配置及空草稿说明不足 | 增加合法 recipe 示例和 actionable style 错误；说明 JSON null 空草稿及初次创建路径 |
| 安装后的 skill 文档链接失效 | 将校样指南打包到 skill 的相对 references 路径 |

完整回归：104 passed，154.97 s。源运行版本导航、旧版本评论及来源清单篡改拒绝由 AppTest 覆盖。CLI agent 在更新后重新绘图，检查原校样完整性、版本评论和安装后的指南，均通过。

界面 agent 完成原始实际使用与 host 修复；其后续浏览器不可用，未据此推断产品通过。控制器在当前浏览器继续验证实际工作区、源运行和精确版本，并进一步检查快速属性编辑、保存、生成和评论。最终实际 replay 通过：文字与 22 pt 字号重开保留，第三版校样及其独立评论/回复生成成功，旧版原评论保留；深浅主题均可读。最终改动区域 7 passed；独立安装包导出、帮助、服务启停与 39 个包文件字节一致性通过。证据见 [验证记录](VALIDATION.md)。
